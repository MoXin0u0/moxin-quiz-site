Privacy Policy

隱私權政策

版本：B02-1.0｜最後更新：2026-10-20

適用範圍

本政策說明墨忻刷題網如何處理學習資料與 Google 雲端同步資料。

墨忻刷題網是本機優先的靜態網頁應用程式。核心功能不要求 Google 登入； 使用者只有在主動啟用跨裝置同步時，才會進行 Google OAuth 授權。

Local-first

本機資料

題庫、題目與圖片、作答紀錄、錯題與複習資料、收藏、不熟題、筆記、Session、 學習目標、題庫工作室草稿及相關設定，主要保存在目前瀏覽器的 IndexedDB 或 localStorage。

使用者可以在不登入 Google 的情況下使用核心學習功能與 PWA 離線功能。 完整備份由使用者自行下載與保存，並與雲端同步機制分開運作。

Optional Cloud Sync

Google 資料與雲端同步

啟用雲端同步時，墨忻刷題網使用 Google Identity Services 與 Google Drive API。 權限範圍限定為 https://www.googleapis.com/auth/drive.appdata， 用於讀寫本應用程式在使用者 Google Drive 中的 appDataFolder。

appDataFolder 是 Google Drive 提供的應用程式專屬隱藏資料空間。 墨忻刷題網不要求可讀取或管理使用者的一般 My Drive 檔案。

為了辨識目前連結的 Google 帳號與同步 profile，應用程式會透過 Google Drive API 取得帳號的穩定 permission ID，以及 Google 回傳的顯示名稱、電子郵件地址與照片連結（若有）。 這些資訊只用於帳號識別、同步狀態與切換帳號流程。

Google OAuth access token 僅保存在目前頁面的記憶體中，不會寫入完整備份； 備份還原也不會復原舊 OAuth 授權或舊裝置的雲端操作狀態。

同步可能涵蓋答題事件、練習與考試 Session、考試答案、收藏、不熟題、筆記、學習目標、 帳號設定、裝置資訊、作者題庫資訊、題庫工作室草稿、使用者題庫及其中的題目與圖片／素材。 為支援多裝置同步及衝突處理，Google Drive 中也可能存有雲端 profile、提交紀錄、檢查點、 修訂索引、刪除標記及歷史版本。並非所有本機備份內容都會自動上傳。

Use & Sharing

資料用途與第三方服務

Google API 取得的資料與同步內容只用於提供帳號識別、跨裝置同步、衝突處理、 裝置管理與資料復原等使用者主動啟用的功能。

本網站目前沒有自建帳號伺服器或自建同步資料庫用來集中保存上述學習資料； 選用的雲端同步內容存放在使用者自己的 Google Drive appDataFolder。 網站由 GitHub Pages 提供靜態託管，因此一般網站連線仍受 GitHub 的服務與隱私政策約束。

墨忻刷題網對從 Google API 取得資訊的使用與傳輸，遵守 Google API Services User Data Policy， 包括 Limited Use requirements；不會將 Google API 資料出售，或用於廣告個人化。 資料使用限於使用者選擇的帳號識別、同步、衝突處理、裝置管理及資料復原。

雲端資料透過 HTTPS 與 Google 服務交換，程式以內容雜湊值核對部分同步物件的完整性； 這不等於本服務承諾具備端到端加密，也不代表 Google 等服務供應商完全無法處理服務所需資料。

User Control

使用者控制與刪除

使用者可以不啟用雲端同步，也可以在「資料與同步中心」解除目前裝置的雲端連結。 解除連結會保留目前裝置的本機資料，不會自動刪除其他裝置或既有雲端資料。

使用者也可以在 Google 帳戶的第三方應用程式存取設定中撤銷墨忻刷題網的 Google 授權。 Google Drive appDataFolder 的保存與刪除亦受 Google Drive 的應用程式資料規則控制。

若要清除目前瀏覽器的本機資料，可以使用瀏覽器的網站資料管理功能。 清除瀏覽器資料與刪除 Google Drive appDataFolder 是兩個彼此獨立的動作。

Feedback & Retention

意見回報、資料保存及第三方處理

由個人開發者「墨忻（MoXin）」提供服務。非公開問題、個人資料權益請求、著作權或安全事件，請使用 Google 意見與問題回報表單；若表單無法使用，可寄至 moxin82771@gmail.com。Google OAuth 同意畫面的使用者支援信箱可能為不同的管理信箱，不影響上述一般回報方式。

表單由 Google Forms 提供；提交的問題類型、主旨、詳細說明、選填的發生頁面、裝置及電子郵件，會由 Google 平台處理並交由本服務提供者查看。電子郵件為選填，依目前表單設定可不登入 Google 提交；未填電子郵件者可能無法收到個別回覆。備用 Gmail 信件包含寄件地址、主旨、內容及自願提供的附件，由 Gmail 平台處理。請勿傳送密碼、OAuth token、身分證件或整份私人備份。

本機資料一般保留在所用瀏覽器中，直到使用者自行清除、瀏覽器依自身機制移除或儲存空間發生變化。Google Drive appDataFolder 的同步資料依使用者的同步、Google 帳戶及平台機制保存；歷史提交、修訂及附件不一定因刪除本機內容或解除連結而立即從雲端清除。本站沒有已驗證的一鍵完整遠端資料刪除功能，也不以檢查點的產生週期作為保存期限。

一般表單案件以結案日起保留 1 年、一般備援電子郵件案件以結案日起保留 2 年為管理基準，未結案案件不從提交日起算；預定每 3 個月人工檢查及清理，不具自動到期刪除功能。資料權利、安全、著作權或法律爭議案件，可能依適用法律與必要性另外處理；收到合法提前刪除請求時亦須個別評估。這項人工機制不表示所有第三方備份、垃圾桶或平台技術紀錄都能在同一時間立即清除。
