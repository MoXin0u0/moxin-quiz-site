# v4.0 R1 — Design System 與題目核心重構

## 目的

R1 暫停新增 P2 功能，先處理兩個根本問題：

1. 全站 UI 過度單調，Light / Dark surface 與文字對比不一致。
2. 題庫工作室把資料正規化與題型轉換混在一起，造成答案跨題型污染。

## Design System

新版使用語意化 token：

- `--bg`
- `--surface`
- `--surface-2`
- `--surface-3`
- `--text`
- `--text-muted`
- `--line`
- `--line-strong`
- `--primary`
- `--accent`
- `--success`
- `--warning`
- `--danger`

桌面主導航改為左側導覽；940px 以下改為底部導覽。既有 `data-nav-*` 與 view ID 保持不變，避免破壞既有功能控制器。

舊 CSS 仍保留作為功能樣式基礎，`v4-design.css` 最後載入，統一覆寫 surface、文字、按鈕、卡片、表單與 Dark Theme 對比。

## 題目 Draft Model

建立、正規化、題型轉換、草稿驗證拆成獨立責任：

- `createQuestionDraft()`
- `normalizeQuestionDraft()`
- `planQuestionTypeChange()`
- `convertQuestionType()`
- `validateQuestionDraft()`
- `toSchemaQuestion()`

### 核心原則

系統不得替作者猜正確答案。

新建四種題型全部使用：

`answer: []`

未設定答案可以保存為工作室草稿，但不能儲存為正式題庫或匯出正式 package。

### 題型轉換

| From | To | 答案 | 選項 |
|---|---|---|---|
| 單選 | 複選 | 保留原唯一答案 | 保留 |
| 複選 | 單選 | 只有一個答案時保留；多答案則清空 | 保留 |
| 選擇題 | 是非 | 清空 | 清除 |
| 選擇題 | 填空 | 清空 | 清除 |
| 是非 | 選擇題 | 清空 | 建立空白 A/B |
| 填空 | 選擇題 | 清空 | 建立空白 A/B |
| 是非 ↔ 填空 | 互換 | 清空 | 無 |
| 同題型 | 同題型 | 保留 | 保留 |

會造成資料遺失的切換必須先顯示確認。

## 舊草稿污染檢查

P1 期間可能出現「單選答案 A 被帶入填空答案」的草稿。R1 不會自動刪除使用者資料。

對 R1 前建立、且填空答案僅為單一 A～H 字母的草稿，工作室會顯示人工核對提醒，並提供「清空可疑答案」。

## 工作室新版資訊架構

桌面：
- 左：題目列表與完成狀態
- 中：題型、題目、答案、詳解與進階設定
- 右：即時預覽與驗證

平板：
- 左題目、右編輯
- 預覽／驗證移到編輯器下方

手機：
- 單欄
- 題目列表橫向滑動
- 主要動作維持可觸控尺寸

題庫名稱、作者、ID、分類、版本移入「題庫設定」。

## R1 暫不包含

- 圖片新增／刪除／預覽
- 批次貼題
- ZIP / JSON 直接開進工作室
- 學習目標
- 考前衝刺
- 首頁 Dashboard

這些功能會在 R1 的題目邏輯與新版視覺通過實機驗收後，接到新的架構上。
