# P6：模擬考模式

## 已完成

- 主導覽新增「模擬考」
- 每個題庫可自訂：
  - 題數：1–100，且不超過題庫總題數
  - 作答時間：10 / 20 / 30 / 45 / 60 / 90 / 120 分鐘
- 開始時隨機抽題與排序
- 考試期間：
  - 不顯示正誤
  - 不顯示詳解
  - 題號導覽
  - 已作答題號標記
  - 上一題 / 下一題
  - 倒數計時
  - 答案與目前題號持續寫入 IndexedDB Session
- 倒數歸零自動交卷
- 未完成模擬考可從「模擬考」中心恢復
- 題庫更新後恢復考試時，已不存在的題目會排除
- 交卷後一次判分
- 考後分析：
  - 總分
  - 答對
  - 答錯
  - 未作答
  - 每題使用者答案
  - 正確答案
  - 詳解
- 模擬考結果同時寫入：
  - attempts（mode = exam）
  - progress
  - reviewSchedule
  - sessions

## 判分

目前每題等權，分數為：

`round(答對題數 / 有效考題數 × 100)`

未作答計入總題數但不計為答對。

## Session

模擬考使用既有 `sessions` store，但以：

- `sessionType = "exam"`
- `mode = "exam"`

與一般 Practice Session 分離。

一般練習的未完成恢復邏輯也已同步修正，不會誤把模擬考當成練習 Session。
