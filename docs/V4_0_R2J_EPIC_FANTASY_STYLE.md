# v4.0 R2J — Epic Fantasy Style Pack

## 目的

R2J 將「史詩幻想」從 R2I 的準備中項目升級為真正可選的 Learning Style Pack。

它不改變資訊架構、按鈕位置或學習流程，只替換視覺 Token、Whole-page Hero 場景、卡片材質、CTA、光影與圖表配色。

## 可切換組合

史詩幻想可與既有色彩模式及場景強度自由組合：

- Light + Epic + Full / Reduced / Off
- Dark + Epic + Full / Reduced / Off

## 獨立場景資產

共 8 張 1600×900 WebP：

- library-light / library-dark
- review-light / review-dark
- exam-light / exam-dark
- stats-light / stats-dark

資產放在 `assets/learning/styles/epic/`，並已加入 PWA App Shell。

## 視覺語言

- Light：象牙白、淡紫、天光藍與暖金
- Dark：深靛紫、午夜藍、魔法紫與暖金光
- 卡片：較深的層次與柔和魔法光暈
- CTA：頁面 Accent → Violet 漸層
- Hero：沿用 R2H Content Safe Area / Art Safe Area，不新增小插畫框
- Mobile：降低場景存在感，操作與文字優先

## 不變更

- IndexedDB
- 題庫 Schema
- 作答 / 複習 / 模擬考 / 統計邏輯
- 題庫工作室與設定頁的後台結構
- R2I 的 Classic Academy / Pure Focus

自然晨光仍保持準備中，待後續 Style Pack 另行製作。
