# v4.0 R2K — Style Differentiation / 風格分家強化

## 目的

R2I 建立 Style Pack 系統，R2J 讓「史詩幻想」可切換；R2K 解決兩套風格仍然太像的問題。

R2K 的原則是：**不同 Style Pack 必須改變主物件、材質、光影與視覺語法，而不只是換色。**

## 經典學院（Academy）

### 物件語言
- 皮革精裝書、古典書櫃
- 黃銅地球儀、星盤與測量儀
- 手稿、鋼筆／羽毛筆、墨水與索引資料
- 沙漏、學院徽章、傳統考場
- 黑板、紙本圖表、研究室

### 材質與介面
- 象牙紙、羊皮紙、胡桃木、黃銅
- 卡片圓角較小、邊框較實體
- Hero 標題使用宋體／襯線系 fallback
- CTA 使用胡桃木 → 黃銅色梯度
- Light 偏日光學院；Dark 偏深木書庫與暖燈

### 四頁場景
- 我的題庫：古典典藏室、地球儀與精裝書
- 今日複習：手稿整理桌、羽毛筆與檯燈
- 模擬考：傳統學院考場
- 學習統計：研究黑板、地球儀與分析工具

## 史詩幻想（Epic）

### 物件語言
- 漂浮魔導書、空中典籍
- 符文球、記憶水晶與發光法陣
- 魔法門、浮空試煉殿堂
- 星象儀、行星軌道與魔法觀測裝置
- 幻想知識城與漂浮建築

### 材質與介面
- 紫晶、藍色魔力光、金色符文、半透明魔法玻璃
- 更大的圓角與 Glow
- 卡片使用半透明 glass-like surface
- CTA 使用紫 → 青魔力梯度
- Hero 加入稀疏星點／魔力粒子紋理

### 四頁場景
- 我的題庫：浮空知識城與漂浮魔導書
- 今日複習：記憶符文球／知識回溯裝置
- 模擬考：魔法試煉門與空中殿堂
- 學習統計：星象儀與知識星圖

## 禁止共用的主視覺

Academy 不以水晶、魔法門、漂浮書、法陣作為主角。
Epic 不以普通現代書桌、盆栽、咖啡杯、一般辦公用品作為主角。

「書、知識、考試、分析」是可以共享的語意，但實際物件表現必須依 Style Pack 重新詮釋。

## Light / Dark

Light / Dark 仍與 Style Pack 獨立：
- Academy Light / Dark 使用同一古典物件語言，不同時間與光影。
- Epic Light / Dark 使用同一幻想物件語言，不同天空、魔力強度與對比。

## 響應式

Whole-page Hero、Content Safe Area、Art Safe Area 維持 R2H 規則。
手機不展示完整場景細節，降低 artwork opacity，確保 CTA 與文字優先。

## 相容性

- learningStyle 值不變：academy / epic / focus
- 不修改 IndexedDB
- 不修改題庫、作答、複習、模擬考或統計邏輯
- R2G 舊場景保留在 repository 作為歷史 fallback，但 Academy / Epic 正式映射到各自 Style Pack 資產
