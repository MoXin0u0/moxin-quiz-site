# v4.0 R1.1 — 工作室互動與提醒調整

## 題型切換提醒

R1.1 將題型切換從瀏覽器原生 `confirm()` 改為網站自己的對話框。

當切換會移除選項或答案時：

- 預設先顯示自訂確認對話框。
- 使用者可勾選「之後不再提醒題型切換」。
- 偏好會寫入既有 `moxin.v3.settings`。
- 設定頁新增「題庫工作室 → 題型切換前確認」開關，可隨時重新開啟。

若提醒已關閉，題型會直接切換，不阻擋操作。

## 復原

每次題型切換完成後，工作室右下角會顯示約 9 秒的非阻塞提示：

`已切換為填空題，原選項已清除、原答案已清除。 [復原]`

按「復原」會還原切換前的完整題目資料。

如果切換後已開始編輯題目，復原狀態會失效，避免把新輸入內容覆蓋掉。

## 工作室 UI refinement

- 左側題目欄加寬。
- 題目摘要改成最多兩行，避免資訊過度截斷。
- 頂部移除多餘的「儲存草稿」按鈕；草稿仍持續自動儲存。
- 右側整份題庫驗證改成摘要式「題目 / 錯誤 / 警告」。
- 整份題庫只顯示少量代表性問題，詳細問題由目前題目區逐題處理。
- 自訂 dialog / snackbar 會跟 Light / Dark Theme 使用相同 Design Token。

R1.1 仍不加入 P2 圖片或批次匯入。
