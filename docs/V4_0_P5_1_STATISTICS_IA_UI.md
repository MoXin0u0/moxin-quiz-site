# 墨忻刷題網 v4.0 — P5.1 Statistics IA & UI

## 目的

P5 不採「所有圖表一路往下堆」的長頁架構。

學習統計正式拆成：

```text
總覽
趨勢
弱點分析
題庫分析
```

## 總覽

只保留高層決策資訊：

- 最近 7 日作答 / 正確率 / 學習日
- 最近 30 日作答 / 正確率 / 學習日
- 優先弱點章節
- 題庫表現摘要
- 7 日迷你作答圖

Hero 的總作答 / 整體正確率維持 Global，避免 scope 語意混亂。

## 趨勢

提供：

- Global 或指定題庫
- 7 / 30 日切換
- 每日作答量
- 每日正確率
- 活躍學習日
- 題目觸及次數

30 日圖表使用水平捲動，不壓縮到無法辨識。

## 弱點分析

提供：

- Global / 指定題庫
- 弱點章節排序
- 樣本不足標記
- 題型正確率
- 全章節正確率
- 刪題 / 異常 timestamp 的資料品質提示

## 題庫分析

保留既有每題庫卡片：

- 題數
- 作答次數
- 正確率
- 目前錯題
- 今日到期
- 熟練度分布

它現在有自己的頁籤，不再跟趨勢與弱點垂直堆疊。

## 效能

第一次進入「學習統計」：

```text
IndexedDB → build statsModel
```

之後切：

```text
總覽 / 趨勢 / 弱點分析 / 題庫分析
```

或切：

```text
7 / 30 日
Global / 題庫
```

都只使用 cached model 與 P5 Analytics Core 重新計算，不重新讀 IndexedDB。

## RWD

- Desktop：4 個次層 Tab、雙欄分析
- Tablet：2 × 2 Tab、主要分析改單欄
- Mobile：Tab 單欄、Hero 壓縮、30 日圖表可橫向捲動
