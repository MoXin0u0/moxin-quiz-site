# B02｜Gmail 備援聯絡信件保存、結案與人工清理 SOP（草案）

## 一、適用範圍與保存原則

- **對象**：透過 `moxin82771@gmail.com` 備用信箱聯絡墨忻刷題網的一般使用者案件，包含一般建議、錯誤回報、勘誤與普通技術協助。必要時涵蓋同一案件的收件、寄件、往返信件與附件。
- **保存期限**：一般案件**自實際結案日起結案後保留 2 年**，不以來信日期起算；未結案案件不開始計算結案後二年期限。
- **檢查頻率**：**每 3 個月人工檢查**是否有到期且不再具保存必要的案件，依據可執行程序清理。**目前沒有自動刪除**或自動封存／自動移除功能，也尚未對既有信件實際清理。
- **特殊案件**：涉及個人資料權利、著作權、資安事件、法律爭議或依法需保存的證據，由負責人依個案必要性、資料最小化及適用法律決定保存、提前移除敏感附件或延長／停止保存；不得無限期無理由留存。依法提出的適當刪除請求不必等滿二年。
- **其他資料不適用**：Google Forms 的一般回覆為**結案後保留 1 年**，獨立管理；本 Gmail 期限不套用使用者自己的瀏覽器／Google Drive 同步資料，也不對整個信箱中的 Google 安全通知、其他專案郵件、非墨忻刷題網業務郵件進行全面刪除。
- 保存期限與季度檢查是**管理決策**，非 Gmail 技術上已自動執行之規則；具體操作與適用的法律例外，正式發布前應審查並驗證。

## 二、人工案件處理流程（待實作驗證）

1. **識別／分流**：區分普通聯絡、未結案、特殊案件與不具保留必要的垃圾訊息；可用 Gmail 標籤輔助整理，但 Gmail 標籤本身**不等於結案日期**，封存亦不等於刪除。避免對全信箱設定統一清除。
2. **結案記錄**：在權限受控、最小化的記錄中保留案件識別碼、類別、實際結案日、預計到期日、最近檢查日、處理結果及必要例外理由；不需複製全文、密碼、令牌或不必要個資至新的清冊。記錄方式尚未指定，不宣稱已有案件系統。
3. **季度盤點**：每三個月依結案記錄找出已達二年且不再需要保存的一般案件，先檢查是否有法律例外、未解決後續或需保留的最小證據；特殊案件須個別裁量並定期重新評估。
4. **人工清理**：在 Gmail 實際介面確認所屬郵件及相關往返、寄件備份、附件、轉寄／另存副本的可控範圍，必要時移除過度敏感內容；執行刪除後確認垃圾桶／永久刪除的實際狀態，**不得將移到垃圾桶等同於立即永久清除 Google 所有系統中的副本**。不得擅稱可刪除寄件者或第三方持有的副本。
5. **完成驗證**：以不含信件全文的必要紀錄記下執行日期、範圍、結果及例外；定期重新核對 Gmail 的共用、委派存取、轉寄、帳戶安全與 Google 提供之刪除行為。測試應使用無敏感資料的測試郵件。
6. **特殊／提前請求**：需要回覆或處理個人資料請求時，依個案及適用法令查核身分、必要的資料範圍與處理方式；不得讓使用者在公開 GitHub Issue 提交身分證、OAuth token 或私人備份。
