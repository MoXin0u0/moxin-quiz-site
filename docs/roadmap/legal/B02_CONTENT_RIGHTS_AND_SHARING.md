# B02｜D-05 第三方題庫與圖片權利規劃（未生效）

**產品決策（2026-10-10）：** 可匯入網路、書籍、考試試題等第三方素材供個人學習，但使用時仍須符合相關著作權規範；若要公開分享題庫，須先確認具有公開散布、傳輸所需的授權或其他合法利用依據。

## 私人使用與公開分享的界線

| 情境 | 原則 |
| --- | --- |
| 本機匯入及個人複習 | 功能允許；私人用途不代表所有重製當然合法。 |
| 下載完整備份、私人跨裝置同步 | 不等同公開發行；仍應確認必要的合法利用依據。 |
| 匯出 ZIP 後給他人或公開下載 | 匯出能力不等於著作權授權；分享前應確認題目、圖片、解析等各項權利。 |
| 網站內建作者題庫／場景圖片 | 開發者須逐項查核來源與對外展示、重製及散布權限。 |
| 來源與權利不明的內容 | 不應直接作為本站對外分享素材。 |

不得將「網路找得到」「免費」「有註明出處」「改幾個字」視為自動取得公開分享權利。法律例外：臺灣《著作權法》第 51 條對私人重製有範圍與條件；第 9 條第 1 項第 5 款排除**依法我國法令舉行**的考試試題與備用試題，但不一定涵蓋出版社原創詳解、編排、圖片或非依法令舉行的題目。

參考：[著作權法](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=J0070017)、[智慧財產局關於試題及原創解析的說明](https://www.tipo.gov.tw/tw/copyright/692-52873.html)。

## 既有作者題庫的來源初步盤點（2026-10-10）

產品負責人已補充：**目前內建作者題庫主要從官方考試題目與網路資料整理而來**，而非宣稱每題均由墨忻原創。這是整份題庫的來源類型說明，**不是逐題來源與授權證明**。

目前 GitHub 程式庫可以確認：

| 現有證據 | 具體值 | 尚無法推論 |
| --- | --- | --- |
| `author-banks.json` | 內建題庫 `ERP_Planner_202509_V06`，題名「ERP 規劃師題庫 2025.09 V06」，443 題，標示整理者 `author: 墨忻` | 題目全部原創、全部來自依法令舉行的考試或都已取得公開傳輸授權 |
| `author-banks/ERP_Planner_202509_V06/manifest.json` | 註記從 `legacy-v1` 移轉，`legacySource` 為 `questions/ERP_Planner_202509_V06_improved_explanations.json` | 這個 GitHub 相對路徑是題目的原始網站或官方發布機關 |
| `author-banks/ERP_Planner_202509_V06/questions.json` | 含題目、選項、解析等實際對外內容 | 目前尚未逐題核對原始來源、個別題目、解析文字與圖片的授權 |

**重要區別**：ERP 規劃師題庫可能涉及專業認證、協會試題、教材或官方考試資料；在未核對考試的主辦機關及法令依據前，不得直接援引《著作權法》第 9 條第 1 項第 5 款將其 443 題一律判為不受著作權保護。網路整理的題目亦須查明原站、原作者、發布條件與獨立解析等權利。

後續清查順序：先確認實際**官方考試名稱、主辦／發布單位及官方出處連結**；其次確認**網路資料來源網站及是否具有公開再利用授權**；再依題目、答案解析及個別圖片分別判定公開使用依據。未能追溯的題目先註記「**來源待確認／公開權利未驗證**」，而非自動認定違法或合法。該清查不代表目前已完成可發布的素材清冊。

## 未來公開分享的權利檢查

題庫及各別圖片／解析的依據可區分為：自行原創、獲第三方授權、開放授權、公有領域、依法令考試試題、其他具體法定利用依據、來源不明。公開分享前記錄素材來源、作者、適用授權或法條、署名條件、可公開傳輸／再散布範圍及查核結果；不能假裝網站具備自動辨識全部版權的能力。

現在不新增強制私人匯入審核或公開分享按鈕；作者現有題庫（待查約 443 題）與學院／史詩場景圖片也不能在未查核前宣稱全部原創或已授權。
