# v4.0 R2E — Practice Experience Redesign

R2E 專門整理真正進入學習後最常停留的畫面，不增加新功能、不改資料結構。

## 題庫詳情

舊版較像篩選器後台；R2E 改成「準備這次練習」：

- 題庫名稱、描述與真實學習摘要放在主 Hero。
- 主 CTA 直接顯示目前篩選後題數並開始練習。
- 未完成 Session 保留「繼續上次練習」。
- 學習清單與題型／難度／章節／關鍵字分成兩層。
- 題目預覽改成有序號、狀態與 metadata 的閱讀式卡片。

保留原有所有 data hooks，因此不改 main.js 的功能控制流程。

## 刷題畫面

R2E 改成 Focus Mode：

- 上方只保留結束、題庫名稱與本輪進度。
- 題目本體置中並限制閱讀寬度。
- 選項使用較大的觸控區與清楚的 A/B/C/O/X key。
- 「提交答案」保持主要動作。
- 收藏與不熟降為次要工具。
- 筆記改為可展開區塊，避免長期佔據視線。
- 答題回饋拆成答案比較、詳解與下一題。
- 完成本輪後以正確率與三項真實統計做收尾。

## 模擬考作答

- 頂部顯示題庫、目前進度與剩餘時間。
- 桌面使用 sticky 題號導覽。
- 平板／手機將題號導覽轉為橫向可捲動列。
- 題目卡仍使用與一般刷題一致的閱讀節奏，但不顯示作答正誤。
- 交卷維持獨立危險操作。

## 模擬考結果

- 真實分數以環形 score card 顯示。
- 題數、答對、答錯、未作答維持真實 result 資料。
- 考後分析重新整理為答案比較與詳解兩層。
- 答錯與未作答仍預設展開。

## 不變更

- IndexedDB
- Schema 2.0
- scoring / session engine
- 收藏、不熟、筆記資料
- 圖片資產
- 模擬考計時與交卷邏輯
- 題庫工作室與設定介面
