# P4：錯題、收藏、不熟題、筆記與 Session 恢復

## 本階段新增

- 題庫詳情加入學習清單切換：
  - 全部題目
  - 錯題
  - 收藏
  - 不熟題
  - 有筆記
- 錯題以 `progress.lastResult === "wrong"` 判定
  - 之後答對時會自動離開「目前錯題」清單
  - 歷史答錯次數仍保留在 progress / attempts
- 練習頁可標記 / 取消不熟題
- 練習頁可新增、更新、清空個人筆記
- 收藏、不熟、筆記皆以 `bankId + questionId` 綁定
- 題庫更新時，只要永久 ID 不變，學習資料可保留
- 題庫詳情偵測最近一筆未完成 Session
- 可繼續未完成 Session
- 題庫更新後恢復 Session 時會自動排除已不存在的題目
- 未完成且當下尚未提交的題目會恢復到同一題

## 資料來源

- `progress`：目前錯題狀態與累積答題資料
- `favorites`：收藏
- `mastery`：目前先用於「不熟」人工標記
- `notes`：個人筆記
- `sessions`：未完成 / 已完成練習 Session
