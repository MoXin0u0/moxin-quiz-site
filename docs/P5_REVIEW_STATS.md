# P5：今日複習、熟練度與學習統計

## 今日複習排程

每次提交答案後會更新 `reviewSchedule`：

| Level | 熟練度 | 答對後下次間隔 |
|---|---|---:|
| 0 | 尚未建立 | — |
| 1 | 學習中 | 1 天 |
| 2 | 學習中 | 3 天 |
| 3 | 熟悉 | 7 天 |
| 4 | 熟悉 | 14 天 |
| 5 | 已掌握 | 30 天 |
| 6 | 已掌握 | 60 天 |

答錯時：

- Level 往回 2 級，最低為 0
- correct streak 歸零
- 下一次排程為 1 天後
- 本輪 queue 仍沿用既有邏輯：答錯題目會在同一輪再次出現

這讓「同輪立即再練」與「跨日間隔複習」分開處理。

## 複習中心

主導覽的「今日複習」現在可使用。

每個題庫提供四種專用入口：

- 今日到期
- 目前錯題
- 收藏
- 不熟題

每次複習仍限制在單一題庫，避免不同題庫的 assets 與 metadata 在同一 Session 中混用。

## 學習統計

主導覽的「學習統計」現在可使用，包含：

- 總作答次數
- 正確率
- 已作答題目數
- 今日到期數
- 各題庫作答次數
- 各題庫正確率
- 各題庫目前錯題
- 各題庫今日到期
- 熟練度分布：
  - 尚未建立
  - 學習中
  - 熟悉
  - 已掌握

## 設計原則

P5 的熟練度模型刻意保持透明、可解釋，之後如果要改成 SM-2、FSRS 或更細的模型，可以保留相同的 `reviewSchedule` repository 邊界再替換演算法。
