P2C / P2C.1 實機驗收包
=========================

重要：這是一個「測試包」，不要把外層 ZIP 直接當題庫匯入。
請先解壓縮，逐個選擇裡面的 JSON / ZIP。

A. 01-direct-and-collision.json
--------------------------------
第一次：
1. 在「我的題庫」選擇這個 JSON。
2. 預期：驗證通過，題目 2、圖片 0、錯誤 0。
3. 點「在題庫工作室中開啟」。
4. 預期：自動切到題庫工作室，直接打開草稿。
5. 預期 ID：p2c-acceptance-direct
6. 預期 Q001 / Q002 都存在。

Collision：
1. 回到我的題庫，用同一檔案先點「匯入到我的題庫」。
2. 再重新選擇同一個 JSON。
3. 預期：檢查畫面提示本機已有同 ID。
4. 「在題庫工作室中開啟」路徑應顯示會使用：
   p2c-acceptance-direct-copy
   （若已重複測過，可能是 -copy-2、-copy-3）
5. 點入工作室後，不可覆蓋原本已匯入的本機題庫。

B. 02-image-assets.zip
-----------------------
1. 選擇 ZIP。
2. 預期：驗證通過，題目 1、圖片 1。
3. 點「在題庫工作室中開啟」。
4. 工作室 Q001 的題目圖片應可看到。
5. Inspector / 圖片資產不能顯示 missing。

C. 03-warning-missing-image.json
---------------------------------
1. 選擇 JSON。
2. 預期：驗證仍通過，但警告至少 1。
3. 警告內容應指出找不到：
   assets/images/Q001/question/missing.png
4. 「在題庫工作室中開啟」仍應可按。
5. 進 Studio 後可看到題目，並能針對缺圖進行修正。

D. 04-invalid-empty-answer.json
--------------------------------
1. 選擇 JSON。
2. 預期：驗證失敗，錯誤至少 1。
3. 應指出 answer 必須是非空陣列。
4. 「匯入到我的題庫」必須 disabled。
5. 「在題庫工作室中開啟」也必須 disabled。

全部通過的驗收條件
------------------
[ ] JSON 可直接建立並開啟 Studio Draft
[ ] 建立後自動導航到工作室，不必再找草稿
[ ] ID collision 不覆蓋舊題庫，而是建立 copy ID
[ ] ZIP 圖片 Blob 與 images 路徑都保留
[ ] Warning 可進 Studio
[ ] Error 不可匯入也不可進 Studio
[ ] Question ID Q001 / Q002 不被任意重編
